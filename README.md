# Olá, sou César Ricciarelli

Sou estudante de Ciência da Computação, com foco em desenvolvimento back-end usando Java, Spring Boot e SQL. Nos meus projetos, pratico a criação de APIs REST, integração com bancos relacionais e testes automatizados.

Estou construindo minha trajetória em TI e busco uma oportunidade de estágio ou nível júnior, com interesse em trabalho remoto. Valorizo código claro, documentação útil e aprendizado em equipe.
